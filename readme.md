# Kafka / Faust Application

## 1. Описание классов и логики работы приложения

Описание классов указано непосредственно в комментариях в файле `models.py`.

## 2. Запуск проекта

Для запуска проекта необходимо:

1. Создать файл `.env`.
2. Запустить Docker Compose:

```bash
docker-compose up
```

## 3. Тестирование

Для тестирования ничего дополнительно делать не требуется.

Необходимо запустить приложение согласно пункту **2**.

Перед запуском Faust-приложения тестовые данные обогащаются самостоятельно, после чего вся информация выводится в логи приложения.

В логах подробно расписан процесс обработки данных.

## 4. Тестовые данные

О тестовых данных позаботятся продюсеры, расположенные в директории:

```text
producers/
```

Продюсеры самостоятельно формируют и отправляют необходимые тестовые данные в соответствующие Kafka-топики.
